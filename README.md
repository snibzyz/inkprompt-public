# inkprompt-public

แม่แบบพรอมต์ของ INKIDEA สำหรับแอปของลูกค้า — **เข้ารหัส** แอปดึงและอ่านเอง

- `meta.json` — ฉบับปัจจุบัน (แฮช · จำนวนไฟล์) แอปเช็กไฟล์นี้เป็นระยะ
- `templates.bin` — ก้อนแม่แบบที่เข้ารหัส

สร้างอัตโนมัติจาก repo พรอมต์ (INKPROMPT) ทุก 15 นาที (เฉพาะไฟล์ที่ติ๊กให้ลูกค้า) — **ห้ามแก้ไฟล์ใน repo นี้ด้วยมือ**

## assets/logos

โลโก้ INKREALM (PNG พื้นโปร่งใส ~1024px) ที่แอปดึงไปใส่ลงปกนิยาย/ปกคลิป — `index.json` บอกไฟล์ + แฮช · แอปดึงเฉพาะไฟล์ที่ต้องใช้และที่เปลี่ยน
รูปทรง `logo` (สัญลักษณ์) · `typo` (ตัวหนังสือ) · `logo_typo` (ประกบกัน) × สี `color` · `white` · `black` · `white_orange` · `mono_white` · `mono_black`
ไม่ได้สร้างจาก Action — เพิ่ม/เปลี่ยนไฟล์ใน `assets/logos/` แล้วอัปเดต `index.json` ด้วย
